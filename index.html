FFC PATCH TOOL

This tool patches supported Craftland map protobuf files using binary protobuf editing and automatic metadata repair.

The patcher directly reads protobuf fields from meta files instead of blindly replacing bytes.

Required ZIP structure:

• UserLevelData_X.bytes
• ProjectData_slot_X.bytes
• ProjectData_slot_X.meta

Every slot must contain all 3 required files.

Slots missing any required file are skipped automatically.

Supported features:

• Skin patching
• UID modification
• Automatic metadata repair
• Automatic ProjectData MD5 recalculation
• Automatic ProjectData size recalculation
• Meta UID update
• Nested ZIP support
• Invalid slot detection
• Multiple UID grouping in output ZIP
• Detailed verification logs
• Real protobuf field parsing

Security / validation:

• UserLevel MD5 is verified before patching
• Invalid UserLevel MD5 cancels slot processing
• ProjectData MD5 mismatch is repaired automatically
• ProjectData size mismatch is repaired automatically

Required conditions:

• Original protobuf structure must remain valid
• Maps must use supported coding/function structure
• Corrupted protobuf files are unsupported
• Unsupported custom map structures may fail
• Broken protobuf field layout may fail
• Random hex edits may corrupt maps

Output ZIP behavior:

• If all slots use same UID, files remain at ZIP root
• If multiple UIDs exist, files are grouped into UID folders automatically

The patcher recalculates:

• UserLevel MD5
• ProjectData MD5
• ProjectData size
• UID metadata fields

This fixes maps where users manually edited files but forgot to update:

• MD5 hashes
• protobuf sizes
• UID metadata
• internal meta values
